# BetterHaptics

Full control over haptics for UI, note types, and more.

- User interface
- Normal notes
- Chain heads
- Chain links
- Arc heads
- Arc tails
- Arc head & tails
- Bombs
- Bad cuts
- Arcs
- Walls
- Saber clash

## Building

Use `qpm s build` to build.

Same goes for `qpm s copy` and `qpm s qmod`.
